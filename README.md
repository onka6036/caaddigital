# CAAD DEVELOPMENT, LLC website

A responsive, single-page marketing website built with plain HTML, CSS and JavaScript. No build step or package installation is required.

## Run locally in Visual Studio Code

1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser. For live reload, install the **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.

The site uses Google Fonts, Unsplash-hosted sample imagery and a Google Maps embed, so those elements require an internet connection.

## Before publishing

- Replace the illustrative portfolio images and concepts with approved company work. The current gallery is explicitly labeled as sample concepts, not client projects.
- The contact and quote forms validate in the browser but are intentionally not connected to a backend or form service. Form submissions are not sent or stored. Connect a secure form endpoint before accepting enquiries.
- Add the company email address and actual social profile links when available. The map currently searches the supplied Panama City Beach address and can be replaced with a configured map embed.
- Review the content, imagery licenses and contact details before publishing.
